# 🌐 Portfólio Pessoal — Fillipe Gomes

Este é o meu portfólio pessoal, desenvolvido com foco em design moderno, responsividade e boas práticas de front-end.  
O projeto foi inspirado no layout do canal [Bedim Code](https://www.youtube.com/@Bedimcode), com customizações próprias para refletir minha identidade e trajetória profissional.

---

## 🧰 Tecnologias Utilizadas
- **HTML5** — estrutura semântica do site  
- **CSS3** — estilização e animações com variáveis e efeitos de gradiente  
- **JavaScript (ES6)** — interatividade e controle de navegação  
- **Git & GitHub** — versionamento e hospedagem do projeto  

---

## 🎨 Destaques
- Design responsivo adaptado para diferentes tamanhos de tela  
- Efeitos sutis de animação com transições suaves  
- Cores e fontes personalizadas  
- Estrutura modular de seções (Home, Sobre mim, Projetos, Contato)
